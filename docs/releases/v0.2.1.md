Banking and marketing starters for platform v0.4.0.

## Changes

- Adopt the renamed Astraform SDK and conformance packages. Existing Java and
  Python imports, APIs and the `remote-domain-conformance` command are unchanged.
- Move the generic Java/Spring provider starter into samples source as
  `starter-java-spring`, with a standalone Maven build. It replaces the SDK Maven
  template artifact and remains separate from the deployment archives.
- Combine marketing readiness advice and feedback on a customer-proposed handoff
  in one conversation. Scheduled and current-boundary configurations use the same
  goal; the models choose their messages and when to stop. Advice and proposal
  feedback do not execute a handoff or clear the campaign for launch.

## Compatibility

- Platform: **v0.4.0**, delivered separately from the samples.
- Java: **`ai.astraform:sdk-java:0.4.5`** from Maven Central.
- Python: **`astraform-sdk==0.3.5`** from PyPI.
- Provider contracts: **1.2.3**.

For source builds, Java provider tests use
`ai.astraform:conformance-java:0.4.5`; Python provider checks use
`astraform-conformance==0.3.5`. Container starters include their runtime
dependencies.

## Downloads and upgrading

Choose Python issued banking, Java issued banking, Java monthly banking or
scheduled marketing from the release assets. Download the archive and matching
`.sha256` file, verify the checksum, then follow the bundled README. The shared
`release-manifest.json` records source revisions, image digests and archive
hashes; each archive also includes its file manifest.

Replace the old Python author-kit distribution when adopting `astraform-sdk`;
do not install both into one environment because they provide the same imports.
Source builds use the checked-in Maven dependencies and PyPI registry locks.

Issued banking and marketing retain their authored receipt conditions and
customer-FINISH requirement. Monthly banking retains native scheduled domain
work and participation through its configured horizon. Installing an SDK does
not upgrade platform capabilities. Goal completion does not certify factual
advice or confirm a real payment or campaign launch.

Preserve platform database and evidence volumes. Marketing domain state and
agency conversation state remain in memory. These single-host examples do not
establish production isolation, high availability or population capacity. Keep
credentials and customer evidence private.

Published v0.2.0 artifacts retain Java SDK 0.4.4, Python SDK 0.3.4 and contracts
1.2.2. Use each historical archive with its own guide and manifest rather than
substituting its image or package versions. See the
[banking guide](https://github.com/astraform/samples/blob/v0.2.1/deploy/banking-starter/README.md),
[marketing guide](https://github.com/astraform/samples/blob/v0.2.1/deploy/marketing-starter/README.md)
and [Java provider starter](https://github.com/astraform/samples/tree/v0.2.1/starter-java-spring)
for setup and configuration.
