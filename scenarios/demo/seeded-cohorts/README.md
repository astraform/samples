# Seeded demo personas

`banking-demo-agents.json` contains 50 invented/generated banking personas and
their scenario configuration. Names, dates of birth, occupations, goals and
initial account records are fictional demo data, not real customer records.
The repository owner confirmed this provenance on 11 October 2026.

This is an older cohort-authoring fixture. Its presence does not establish that
the current native simulation supports every legacy field or a shared run of
50 customers. For the current SDK workflow, use the
[banking customer guide](../../../banking-advice-agent/README.md).

Adapt examples with synthetic records when sharing them. Keep real customer
data, credentials and run evidence in your own private environment. These
Astraform-authored fixtures use the repository's [Apache 2.0 license](../../../LICENSE).
